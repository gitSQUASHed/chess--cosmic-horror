# T-17 Phase 2 screen effects

## Scope
- Vignette, grain, gentle fisheye as screen shaders.
- Threat response driven by the guiding-hand value: white bloom, denser static, shake. At maximum the king stays visible.
- Phase 1 gets light grain only.

## Acceptance criteria
- Effects scale continuously with threat and never fully blind the player.
- Each effect can be toggled for debugging.
