# T-08 Phase 1 director and escalation

## Scope
Drives `Hands` for the two-minute [Phase 1 schedule](../plan/gameplay/enemy_curve.md).

| Time | Change |
|---|---|
| 0:00 | 1 hand, sweep and grab level 1, interval about 4 s |
| 0:30 | 2nd hand, walls enabled |
| 1:00 | Sweep and grab to level 2 |
| 1:30 | 3rd hand |
| 2:00 | End Phase 1 |

- Chooses what to request; `Hands` decides who and where.
- Debug fast-forward key.

## Acceptance criteria
- The schedule matches the table on a real-time run.
- Hands never act in a way that violates T-05 rules.
