# T-09 Board collapse transition

## Scope
- Tiles fall away at 2:00, the king falls into darkness, the screen goes black, short arrival hold, then Phase 2 start.
- Arrival textbox line via T-15.
- Active hands finish or cancel cleanly; Phase 1 state carries over (colour, escape side, upgrade levels).

## Acceptance criteria
- Transition cannot be interrupted by capture.
- Phase 2 starts with levels carried over.
